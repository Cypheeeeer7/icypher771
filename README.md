# icypher771 - C++ URL Threat & Phishing Auditor

**icypher771** is a high-performance, command-line security tool written in **C++** designed to analyze URLs, detect potential phishing indicators, flag insecure protocols, and evaluate threat risk scores instantly.

---

## 🚀 Features

- ⚡ **High Performance:** Written in raw C++ for lightning-fast execution.
- 🔍 **Protocol Verification:** Detects unencrypted HTTP connections.
- 🎣 **Phishing Keyword Detection:** Scans URL structures for sensitive terms (`login`, `verify`, `secure`, etc.).
- 🌐 **TLD Risk Assessment:** Flags high-risk domain extensions.
- 📊 **Risk Scoring System:** Generates a structured 0-100 risk score and threat report.

---

## 🛠️ Compilation & Usage

### 1. Clone the Repository
```bash
git clone [https://github.com/Cypheeeeer7/icypher771.git](https://github.com/Cypheeeeer7/icypher771.git)
cd icypher771
Compile the Source Code
Make sure you have a C++ compiler installed (like g++):

g++ icypher771.cpp -o icypher771

Run the Tool
Pass any URL as an argument to scan it

./icypher771 [https://example.com/login](https://example.com/login)
